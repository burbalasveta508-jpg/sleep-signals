# Сигналы: лекции для сна

Раз в сутки программа собирает статистику YouTube по выбранным вами каналам и строит отчёт в стиле Signal Surfer.

## Что есть в отчёте

- **Подборка по датам**: выпуск сигналов на каждый день, архив за 30 дней.
- **Активация**: старое видео вдруг ускорилось (VPH ≥ ×3 от обычного).
- **Превышение**: свежее видео набрало ≥ ×3 от медианного видео канала.
- **Вечнозелёные**: старые видео, которые стабильно набирают просмотры.
- **Новые сигналы** и фильтр **«Когда нашли сигнал»**.
- **Показатели**: на дату подборки или по последним замерам.
- **Кто в кадре**: есть ли лицо на обложке (автоматически, иногда ошибается на рисунках).
- **Свободный рынок / «Рынки и конкуренция»**: название переводится на RU/EN/DE/ES (на своём языке ищется по оригиналу), похожие видео ищутся на YouTube, считается сходство названий. Каждый день проверяются 8 самых сильных сигналов (настраивается).
- **Перевод названий на русский** и поиск по переводу.
- **Темы**: история, космос, наука, мифы… Список и ключевые слова задаются в `config.json` → `categories`.
- **♡ Понравившиеся** (сохраняются в вашем браузере), **Обложки** (сетка обложек), **Каналы** (таблица с динамикой).

## Какие каналы отслеживать

Файл `channels.txt`, по одному каналу в строке (ссылка, @имя или ID):
```
https://www.youtube.com/@SomeSleepChannel
@AnotherChannel
```
Отслеживаются только каналы из списка. Чтобы убрать канал, удалите строку. На GitHub файл можно править прямо на сайте: откройте `channels.txt` → значок карандаша → Commit changes. Изменения подхватятся при следующем обновлении.

## Запуск на компьютере (Windows)

```
cd D:\sleep-signals\sleep-signals
$env:YT_API_KEY="ваш_ключ"
py signals.py update
start report\index.html
```
`update` делает всё сразу: статистику, сигналы, перевод, лица, рынки и отчёт.

Для распознавания лиц один раз установите: `py -m pip install opencv-python-headless`. Без этого пакета всё остальное работает.

Другие команды:
- `py signals.py stats` — какие каналы отслеживаются;
- `py signals.py report` — пересобрать отчёт без обращения к YouTube;
- `py signals.py demo` — демо-отчёт на вымышленных данных.

## Автоматически на GitHub (ссылка, обновляется сама)

1. Загрузите папку в **публичный** репозиторий GitHub (через GitHub Desktop).
2. На сайте откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Имя: `YT_API_KEY`, значение: ваш ключ.
3. **Settings → Pages →** Source: **GitHub Actions**.
4. **Actions → daily-update → Run workflow**, чтобы запустить первый раз.
5. Ссылка на отчёт: `https://ВАШ-ЛОГИН.github.io/sleep-signals/`. Дальше отчёт обновляется сам каждый день в 05:17 по Варшаве.

Каналы добавляются прямо на сайте GitHub: `channels.txt` → карандаш → вставить ссылки → **Commit changes**.

База хранится в релизе **db** (раздел Releases справа на странице репозитория) и каждый день перезаписывается. Не удаляйте этот релиз. После переезда на GitHub запускать `update` у себя на компьютере не нужно.

## Квота YouTube (10 000 единиц в сутки бесплатно)

| Действие | Стоимость |
|---|---|
| Обновление 50 каналов (~15 000 видео) | ~350 ед. |
| Проверка рынка одного видео (4 языка) | ~400 ед. |
| 8 проверок рынков в день | ~3 200 ед. |

Число проверок рынков меняется в `config.json` → `market.checks_per_run`.

## Настройки (config.json)

- `metrics`: пороги активации, превышения и вечнозелёных.
- `niche.min_duration_min`: минимальная длина видео (по умолчанию 30 минут).
- `market.langs`: языки рынков; `busy_similarity` / `partial_similarity` — пороги «Занят» / «Частично свободен».
- `categories`: темы и слова, по которым видео к ним относятся.

## Ограничения

- История просмотров по дням копится с первого запуска. YouTube не отдаёт её за прошлое.
- Подписчики в YouTube API округлены.
- Перевод идёт через бесплатные сервисы (Google Translate без ключа, MyMemory). Если они недоступны, перевод и рынки пропускаются до следующего дня.
- Правила YouTube API ограничивают хранение данных. Для личной аналитики это не проблема.
